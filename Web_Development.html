02 / THE BIG PICTURE

What is web development?

The process of building and maintaining websites and web applications.

◫

Content

Information people read or view: text, images, links, videos, and more.

◈

Design

How a site looks, including colors, spacing, layout, and typography.

⌁

Function

What a site can do, such as respond to clicks, submit forms, or update content.

Examples: school websites, online stores, blogs, portfolios, and social media platforms.
Speaker notesWeb development is more than writing code. It involves organizing information, deciding how a page should look, and creating useful interactions. Websites can be simple pages or large applications used by millions of people.

04 / HTML BASICS

Meet HTML.

HTML stands for HyperText Markup Language. It describes the structure and meaning of webpage content.

HTML can organize…

  • Headings and paragraphs
  • Images and hyperlinks
  • Lists and tables
  • Forms and input fields
hello.html
<h1>Hello, world!</h1>
<p>This is my first webpage.</p>

Hello, world!

This is my first webpage.

Speaker notesHTML is a markup language, not a programming language in the traditional sense. It uses elements to label and organize content so browsers can interpret it. In the example, h1 creates a main heading and p creates a paragraph.
05 / READING THE CODE

Tags build elements.

Most HTML elements use an opening tag, content, and a closing tag.

Element anatomy01 line
<p>   This is a paragraph.   </p>
  ↑          ↑                   ↑
 opening   content             closing
  tag                         tag

<h1>

Main heading

<p>

Paragraph

<a>

Hyperlink

Some elements are void elements and do not have closing tags, such as <img> and <br>.
Speaker notesTags are the labels written between angle brackets. An element usually includes the opening tag, its content, and the closing tag. Notice the slash in the closing tag. Images and line breaks are examples of elements that do not wrap content and therefore do not use closing tags.
06 / THE HTML SKELETON

A webpage has a structure.

This starter template gives the browser the basic information it needs.

index.htmlHTML5
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <title>My First Website</title>
  </head>
  <body>
    <h1>Welcome!</h1>
    <p>This is my first page.</p>
  </body>
</html>

<head>

Metadata and the browser-tab title.

<body>

The content displayed on the page.

<html>

The root element containing the document.

Speaker notesDOCTYPE tells the browser to use modern HTML standards. The html element wraps the document. The head contains information about the page, including its title, while the body contains the main visible content. The meta charset declaration supports a wide range of characters.
07 / ORGANIZE CONTENT

Headings give content hierarchy.

Use headings to organize sections, then paragraphs for regular text.

text-elements.html
<h1>My Website</h1>
<h2>About Me</h2>
<p>
  I am learning web development.
</p>
<h2>My Hobbies</h2>
<p>Music, art, and coding.</p>

My Website

About Me

I am learning web development.

My Hobbies

Music, art, and coding.

HTML provides six heading levels, <h1> through <h6>. Choose them by structure, not just by the size you want.
Speaker notesHeadings make information easier to scan. H1 is generally the main page heading, while h2 can label major sections. The exact visual appearance can later be changed with CSS, so we should choose headings based on meaning and organization.
08 / CONNECT & DISPLAY

Links connect. Images illustrate.

Make a link

link.html
<a href="https://example.com">
  Visit Example
</a>

The href attribute tells the browser where the link should go.

Add an image

image.html
<img src="picture.jpg"
     alt="A mountain view">

src gives the image location; alt provides a text alternative.

Use meaningful alt text for informative images. If an image is purely decorative, an empty alt value (alt="") is often appropriate.
Speaker notesLinks let visitors move to other pages or websites. Images need a source that points to an available image file or URL. Alt text is important for accessibility, especially for people using screen readers, and also helps when an image cannot load.
09 / EXTRA INFORMATION

Attributes add details.

Attributes are written inside the opening tag and provide extra information about an element.

attributes.html
<a href="https://example.com"
   target="_blank">
  Open website
</a>

href

Link destination

src

Resource location, such as an image

alt

Text alternative for an image

target="_blank" usually opens the link in a new tab or browsing context. For external links, consider rel="noopener noreferrer" as a security and privacy best practice.
Speaker notesAttributes are name-and-value pairs in an opening tag. Here, href sets the destination, and target blank requests a new browsing context. Attributes make elements more useful, but the attribute needs to be appropriate for the element being used.
10 / YOUR FIRST BUILD

Build a page in five steps.

You can practice HTML on a computer or even on a phone using a code editor.

Open a code editor, such as Acode.
Create a file named index.html.
Write the basic HTML document structure.
Add headings, paragraphs, links, or images.
Save the file, then open it in a browser or preview tool.
Change some text and refresh to see the result.
Tip: HTML files end in .html. A file name like index.html is a common starting point.
Speaker notesYou don't need expensive equipment to start. A code editor lets you write the HTML, and a browser renders it as a webpage. Save changes before previewing. If a change does not appear, check that the file was saved and that you are previewing the correct file.
11 / PUT IT TOGETHER

A simple profile page.

This example combines a title, headings, paragraphs, a list, and a link.

profile.htmlExample
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>My Profile</title>
</head>
<body>
  <h1>My Profile</h1>
  <p>Welcome to my page!</p>
  <h2>My Interests</h2>
  <ul>
    <li>Music</li>
    <li>Art</li>
  </ul>
</body>
</html>
BROWSER PREVIEW

My Profile

Welcome to my page!

My Interests

  • Music
  • Art
Speaker notesHere we combine the building blocks. The ul element creates an unordered list, and each li element represents one item. Notice that HTML elements can be nested inside other elements. Good indentation helps us see which elements belong together.
